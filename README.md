# 个人记账（Personal Ledger）

一款运行在 Windows 和 macOS 上的本地桌面记账应用。简单、可靠、开箱即用：不做社交、不含广告、不上传任何数据。

## ✨ 功能

- **记一笔**：支持支出和收入，两级分类（一级大类 + 二级小类），日期、备注
- **账单列表**：月份切换、收支类型/分类筛选、备注关键词搜索、编辑、删除、当月合计
- **统计报表**：本月收入/支出/结余汇总卡片、本月收支构成环形图、近 12 个月收支趋势折线图、当月分类占比饼图
- **分类管理**：所有分类均可自定义增删改（内置 15 个一级大类、53 个二级小类）
- **数据备份**：一键导出 CSV（Excel / WPS 直接打开，中文无乱码）

## 🔒 数据与隐私

所有数据保存在本机（SQLite 单文件数据库），无需联网、不上传任何数据。卸载应用不会删除数据，重装后数据仍在。

## 🛠 技术栈

- 桌面框架：[Tauri 2](https://tauri.app/)（安装包仅约 3.6MB，启动快、省内存）
- 前端：Vue 3 + TypeScript + Vite + Element Plus + ECharts + Pinia
- 存储：SQLite（本地单文件，事务安全）
- 金额以整数「分」存储，杜绝浮点误差

## 🔨 本地开发

环境要求：Node.js 24 LTS、Rust stable、MSVC Build Tools（Windows）/ Xcode（macOS）。

```bash
npm install          # 安装依赖
npm run tauri dev    # 开发模式（首次编译较久属正常）
npm run tauri build  # 打包安装包
```

## 🗂️ 内置分类体系

支出 10 个一级大类：餐饮饮食、交通出行、购物消费、居住住房、通讯网络、娱乐休闲、医疗健康、教育学习、人情往来、其他支出；
收入 5 个一级大类：工资薪金、理财投资、兼职副业、人情往来、其他收入。
所有分类均可按需增删改。
